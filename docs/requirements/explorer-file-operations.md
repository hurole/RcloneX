## 1. 背景与目标

当前 Explorer 仅支持**浏览 / 新建目录 / 删除 / 跨盘复制 / 生成公开链接**，无法完成"上传 → 管理 → 下载"的文件操作闭环，是本项目最大体验缺口。

**本迭代目标**：补齐 6 项能力，使 Explorer 达到生产可用水平：

| 编号  | 功能          | 一句话描述                        |
| :---: | :------------ | :-------------------------------- |
| FR-01 | 上传文件      | 拖拽/选择本地文件上传至当前目录   |
| FR-02 | 下载文件/目录 | 单文件流式下载；目录打包下载      |
| FR-03 | 重命名/移动   | 文件/目录重命名与跨目录、跨盘移动 |
| FR-04 | 文件搜索      | 递归搜索当前远端下文件/目录       |
| FR-05 | 多选批量操作  | 勾选多项后批量删除/复制/下载      |
| FR-06 | 目录统计      | 查看目录占用大小与文件数          |

**成功标准**：以上 6 项功能在 `--rc-user/--rc-pass` 鉴权的 rcd（v1.54+，建议 v1.66+）环境下全部可用；新建 API 均有配套单元测试；全部文案走 i18n。

## 4. 功能需求明细

### FR-01 上传文件

#### 4.1.1 功能概述

支持将本地文件/目录上传至当前浏览目录。核心交互为**拖拽上传**与**点击选择**，上传过程进入独立队列抽屉，实时展示进度并可取消/重试。

#### 4.1.2 交互流程

```
[用户拖拽文件到 Explorer 内容区] 或 [点击工具栏"上传"按钮选择文件]
        │
        ▼
上传队列抽屉打开（右上角滑出，含 N 个任务条目）
        │  ├─ 单文件：直接开始上传
        │  └─ 目录（webkitdirectory）：递归展开为多条文件任务
        ▼
逐条上传：进度条（percent）、速度、大小、取消按钮
        ├─ 成功 → 绿色对勾，可"重试失败"之外无需操作
        └─ 失败 → 红色感叹号 + 错误原因（tooltip），提供"重试"按钮
        ▼
全部完成 → 抽屉顶部汇总"成功 X / 失败 Y"，自动刷新当前目录列表
```

#### 4.1.3 UI 规格

| 元素         | 规格                                                                                                                              |
| :----------- | :-------------------------------------------------------------------------------------------------------------------------------- |
| 上传入口     | ① 工具栏新增"上传"按钮（`Upload` 图标，位于"新建文件夹"左侧）；② Explorer 内容区支持整区拖拽，拖入时显示高亮遮罩"释放以上传"      |
| 上传队列抽屉 | `Sheet`（shadcn/ui，从右侧滑出，宽度 ~400px）；标题"上传队列 (N)"；`sonner` 进度反馈                                              |
| 任务条目     | 文件名、相对路径（目录内文件）、大小、`Progress` 进度条（shadcn/ui）、速度（如 `1.2 MB/s`）、取消按钮（上传中）、重试按钮（失败） |
| 上传中行为   | 禁止切换远端/目录（或切换后提示"上传进行中"）；允许同时开始多个任务（并发上限 3）                                                 |
| 完成行为     | 汇总统计 + 自动 `loadFiles` 刷新列表；关闭抽屉不影响进行中的上传                                                                  |

#### 4.1.4 API 契约

**接口**：`POST {rclone_rc}/operations/uploadfile`

| 参数     | 类型                | 必填 | 说明                                          |
| :------- | :------------------ | :--- | :-------------------------------------------- |
| fs       | string              | ✅   | 远端，如 `drive:`                             |
| remote   | string              | ✅   | 当前目录路径（含结尾 `/`），如 `photos/2024/` |
| （Body） | multipart/form-data | ✅   | `file` 字段携带文件二进制流                   |

**响应**：成功 `{}`；失败返回 `{ "error": "<message>" }`。

**错误处理**：

- 404 → 目标目录不存在，提示后刷新列表。
- 401 → 走全局拦截器（清理凭证跳转登录）。
- 网络中断/超时（10s 默认）→ 任务标记失败，可重试。
- 同名文件存在 → **默认覆盖**（rclone uploadfile 行为），对话框确认后执行。

#### 4.1.5 边界与约束

- 单文件大小无硬限制（依赖 rcd 配置与浏览器内存，大文件建议流式）；>500MB 文件在任务条目展示警告图标"大文件，请耐心等待"。
- 上传中刷新页面 → 队列丢失（前端状态），刷新后提示"上传已中断"。
- 目录递归：使用 `input.webkitdirectory`；空目录不上传（rclone 语义）。

#### 4.1.6 验收标准（AC）

- [ ] AC-1.1 拖拽 3 个文件，队列出现 3 条任务，均成功，列表自动刷新出现新文件。
- [ ] AC-1.2 上传 1 个大文件（>100MB）过程有进度与速度展示，可中途取消。
- [ ] AC-1.3 断网后上传失败，任务标红，恢复后点"重试"成功。
- [ ] AC-1.4 上传到不存在的目录，提示错误并引导刷新。

### FR-02 下载文件/目录

#### 4.2.1 功能概述

- **单文件**：点击下载，浏览器直接保存文件。
- **目录**：递归拉取清单后打包为 `zip` 下载。

#### 4.2.2 交互流程

```
单文件：文件行/卡片 hover → "下载"按钮 → 触发浏览器下载（带进度 toast）
目录：目录行 hover → "下载"按钮
    → 弹确认对话框（显示预估文件数与大小[可选]）
    → 前端递归 list 收集清单 → 经临时 serve 逐个下载 → JSZip 打包 → 触发 zip 下载
    → 大目录显示"正在打包 (i/N)"进度条
```

#### 4.2.3 UI 规格

| 元素         | 规格                                                                                                                    |
| :----------- | :---------------------------------------------------------------------------------------------------------------------- |
| 入口         | 文件/目录行 hover 操作组新增"下载"按钮（`Download` 图标，位于"公开链接"左侧）；目录下载按钮点击后若未确认弹窗则直接打包 |
| 目录打包进度 | 复用全局 `sonner` loading toast（"正在打包 xxx/yyy 个文件"），完成后成功 toast + 自动下载                               |
| 文件大小限制 | 目录内文件总数 > 500 或估算总大小 > 2GB 时二次确认（提示耗时风险）                                                      |

#### 4.2.4 API 契约

**重要说明（rclone v1.69 实测）**：rclone RC **没有通用下载接口**（`operations/downloadfile` / `operations/cat` 均不存在）。本实现采用**双层策略**：

| 策略 | 触发条件 | 实现 |
| :--- | :--- | :--- |
| A. publiclink | backend 支持（Drive/S3 等云盘） | `operations/publiclink` 获取链接 → `fetch` 下载 |
| B. 临时 serve http | publiclink 不可用（local 等） | `core/command` 异步启动 `rclone serve http`（随机端口 + `--read-only` + `--allow-origin *`）→ 从端口下载 → `job/stop` 停止 |

**目录/批量打包**：复用**单个**临时 serve 服务下载全部文件（并发 3），避免逐文件启停服务。

**接口 A：单文件（publiclink，backend 支持时）**：`POST {rclone_rc}/operations/publiclink`

| 参数   | 类型   | 必填 | 说明                            |
| :----- | :----- | :--- | :------------------------------ |
| fs     | string | ✅   | 远端，如 `drive:`               |
| remote | string | ✅   | 文件完整路径，如 `photos/a.jpg` |

**接口 B：临时 serve（兜底）**：`POST {rclone_rc}/core/command`

```json
{ "command": "serve", "arg": ["http", "--addr", "127.0.0.1:4xxxx", "drive:", "--read-only", "--allow-origin", "*"], "_async": true }
```

返回 `{ "jobid": N }`；随后 `GET http://127.0.0.1:4xxxx/{remote}` 下载；最后 `POST /job/stop`（body `{ "jobid": N }`）清理。

**接口 C：目录清单（递归）**：`POST {rclone_rc}/operations/list`

```json
{ "fs": "drive:", "remote": "photos", "opt": { "recurse": true } }
```

响应 `list[]` 含 `Path`（完整路径）、`Size`、`IsDir`。

**接口 D：目录打包**：前端 `JSZip` 组装（详见 4.2.5 设计决策）。

#### 4.2.5 设计决策说明

| 方案                | 说明                                                   | 结论                                                                 |
| :------------------ | :----------------------------------------------------- | :------------------------------------------------------------------- |
| A. 前端递归 + JSZip | 逐文件下载（并发 3）→ 写入 zip → 浏览器保存            | ✅ **主方案**：无额外服务依赖、进度可控                              |
| B. serve http zip   | 临时 `serve/http` + `?zip` 参数                        | ⚠️ 备选：RC 环境通常无 serve 模块；本期以 `core/command` 临时 serve 作为下载兜底 |

**约束**：方案 A 对大目录（>2GB）耗时长，仅以二次确认兜底；失败文件跳过并计入汇总（"成功 X / 失败 Y（已跳过）"）。

#### 4.2.6 验收标准

- [ ] AC-2.1 单文件下载成功，文件名/大小正确。
- [ ] AC-2.2 目录（含子目录、≥10 个文件）下载得到结构正确的 zip。
- [ ] AC-2.3 下载中部分文件失败（模拟网络中断），汇总展示跳过数量，其余正常打包。
- [ ] AC-2.4 空目录下载提示"目录为空，无需下载"。

### FR-03 重命名 / 移动

#### 4.3.1 功能概述

- **重命名**：单文件/目录在当前目录内改名。
- **移动**：文件/目录移动到同远端其他目录（跨目录）或跨远端。
- 复用现有"复制"对话框交互，增加"移动"模式；单文件移动时支持目标改名（=重命名+移动二合一）。

#### 4.3.2 交互流程

```
重命名：行 hover "重命名"按钮 → Dialog（当前名预填）→ 校验非空/无路径分隔符 → 提交
移动：行 hover "移动"按钮 → 移动对话框（同复制对话框：目标远端 + 目标路径 + 目标文件名[可选]）
    → 若目标存在同名项 → 二次确认"将覆盖" → 提交
    → 成功后 toast + 刷新当前目录（源目录）与目标目录
```

#### 4.3.3 UI 规格

| 元素          | 规格                                                                                                                         |
| :------------ | :--------------------------------------------------------------------------------------------------------------------------- |
| 重命名 Dialog | 复用 Dialog 模式；表单：新名称（`Input`）；校验：非空、不含 `/`、不含 `\`；提交按钮 loading 态                               |
| 移动 Dialog   | 在现有 CopyDialog 基础上增加 mode 状态（`copy \| move`）；目标文件名输入框预填原名；同远端移动时不显示"覆盖确认"以外的冗余项 |
| 行操作组      | 现有 `[分享][复制][删除]` 扩展为 `[下载][分享][移动][重命名][删除]`（空间不足时收纳进 DropdownMenu）                         |
| 覆盖确认      | 目标存在时（可先发 `operations/stat` 探测，失败则跳过探测直接执行）弹出红色确认框                                            |

#### 4.3.4 API 契约

**接口**：`POST {rclone_rc}/operations/moveto`

| 参数      | 类型   | 必填 | 说明                                                                         |
| :-------- | :----- | :--- | :--------------------------------------------------------------------------- |
| srcFs     | string | ✅   | 源远端，`drive:`                                                             |
| srcRemote | string | ✅   | 源完整路径（含文件名），`photos/a.jpg`                                       |
| dstFs     | string | ✅   | 目标远端，同盘移动=srcFs                                                     |
| dstRemote | string | ✅   | 目标完整路径（**含新文件名**），`archive/a.jpg`；重命名场景即 `photos/b.jpg` |

**响应**：成功 `{}`；失败 `{ "error": "<message>" }`。

**错误处理**：

- 目标已存在且未确认 → 前端拦截并二次确认。
- `dstRemote` 目标父目录不存在 → rclone 自动创建（moveto 行为），无需额外处理。
- 移动进行中刷新 → 依赖 rclone 原子性（copy+delete），结果以实际为准，不做事务回滚。

#### 4.3.5 边界与约束

- 目录移动 = 整树移动（rclone moveto 支持目录），目标冲突时需用户确认覆盖语义（合并 vs 替换 → **默认按 rclone 行为：合并，同名覆盖**）。
- 禁止源==目标（前端校验，避免空操作）。
- 跨盘移动保留元数据（ModTime）由 rclone 保证。

#### 4.3.6 验收标准

- [ ] AC-3.1 单文件重命名成功，列表立即更新。
- [ ] AC-3.2 单文件同盘移动到子目录成功，源消失、目标出现。
- [ ] AC-3.3 跨盘移动成功（如 `drive:` → `s3:`）。
- [ ] AC-3.4 目标同名存在时弹出覆盖确认，确认后覆盖成功。
- [ ] AC-3.5 非法名称（含 `/`、空串）被前端拦截且提示。

### FR-04 文件搜索

#### 4.4.1 功能概述

在当前远端**递归**搜索文件/目录，支持正则/通配符过滤，结果可点击跳转定位。

#### 4.4.2 交互流程

```
工具栏新增搜索框（Input + Search 图标）
    │ 输入 ≥2 字符并防抖 400ms 后触发
    ▼
进入"搜索模式"：内容区替换为结果列表（Path 高亮匹配片段）
    ├─ 点击目录结果 → 进入该目录（退出搜索模式）
    └─ 点击文件结果 → 定位到其所在目录并高亮该文件（退出搜索模式）
    ▼
清空输入或按 ESC → 退出搜索模式，恢复目录浏览
```

#### 4.4.3 UI 规格

| 元素     | 规格                                                                                           |
| :------- | :--------------------------------------------------------------------------------------------- |
| 搜索框   | 工具栏面包屑右侧新增 `Input`（宽度 ~220px，`Search` 图标前缀，可清空）；输入即搜，防抖 400ms   |
| 搜索模式 | 内容区顶部显示"搜索：'xxx' 在 drive: 下，共 N 个结果"，结果表格列：名称/完整路径/大小/修改时间 |
| 结果高亮 | 匹配片段 `<mark>` 高亮                                                                         |
| 空结果   | 空状态：`SearchX` 图标 + "未找到匹配项"                                                        |
| 取消     | 搜索框清空、ESC、或点击远端切换均退出搜索模式                                                  |

#### 4.4.4 API 契约

**接口**：`POST {rclone_rc}/operations/list`（递归 + 过滤）

```json
{
  "fs": "drive:",
  "remote": "",
  "opt": {
    "recurse": true,
    "filter": {
      "IncludeRule": ["(?i)keyword.*"]
    }
  }
}
```

| 参数          | 说明                                                                                                                                                          |
| :------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `opt.recurse` | `true` 递归列出                                                                                                                                               |
| `opt.filter`  | FilterRule 结构：`IncludeRule`（包含匹配）/ `ExcludeRule`（排除匹配）；使用**前缀/glob 或正则**（推荐用户输入默认转为 glob：`*keyword*`，高级用户可切换正则） |

**响应**：`list[]`（同 listDirectory，含 `Path`、`Name`、`Size`、`IsDir`、`ModTime`）。

**降级策略**：若 rcd 版本不支持 `opt.filter`（返回错误），退化为 `recurse: true` 全量拉取 + **前端过滤**（输入关键字大小写不敏感子串匹配），并 toast 提示"当前使用本地过滤"。

#### 4.4.5 边界与约束

- 仅在**当前选定远端**范围内搜索，不做跨盘聚合搜索。
- 根目录递归全量列表在超大存储（>10 万对象）时耗时较长：搜索框旁显示加载态；可增加"搜索目录范围"（默认当前目录递归）。
- 输入少于 2 字符不触发搜索。
- 搜索模式不占用文件操作：结果行仍支持下载/分享/复制/删除。

#### 4.4.6 验收标准

- [ ] AC-4.1 输入关键字后返回包含子目录的递归结果，匹配片段高亮。
- [ ] AC-4.2 点击目录结果跳转进入对应目录；点击文件结果定位到所在目录。
- [ ] AC-4.3 清空/ESC 退出搜索恢复原浏览状态。
- [ ] AC-4.4 无结果时展示空状态。
- [ ] AC-4.5 后端 filter 失败时降级为前端过滤且提示。

### FR-05 多选批量操作

#### 4.5.1 功能概述

列表/网格视图支持勾选多个条目，进行**批量删除 / 批量复制 / 批量下载**。

#### 4.5.2 交互流程

```
行首新增 Checkbox
    ├─ 表头"全选/取消全选"（仅勾选当前页）
    └─ 勾选 ≥1 项 → 底部浮现批量操作栏（sticky）
批量删除 → 确认 Dialog（"将删除 N 项，不可恢复"）→ 逐项 deletefile/purge
批量复制 → 复制 Dialog（目标远端+路径）→ 逐项 sync/copy（或循环 operations/copyfile）
批量下载 → 确认（大文件提示）→ 同 FR-02 打包流程（多选文件合并打包）
完成后：toast 汇总（成功/失败）+ 刷新列表 + 清空选择
```

#### 4.5.3 UI 规格

| 元素         | 规格                                                                             |
| :----------- | :------------------------------------------------------------------------------- |
| 选择状态     | `Set<string>`（key=`Path`）集中管理；列表/网格视图共用同一选择集，切换视图不丢失 |
| 行 Checkbox  | 列表视图首列；网格视图卡片左上角 hover 显示                                      |
| 全选         | 表头 checkbox 控制"当前目录所有条目"；半选状态展示（`indeterminate`）            |
| 批量操作栏   | 底部 sticky 深色条：`已选 N 项` + `[删除] [复制] [下载] [清空选择]`              |
| 批量删除确认 | Dialog 红色主题，明确"不可恢复"；逐项失败单独列出                                |

#### 4.5.4 API 契约

**批量删除**：组合调用

| 项类型 | 接口                    | 参数             |
| :----- | :---------------------- | :--------------- |
| 文件   | `operations/deletefile` | `{ fs, remote }` |
| 目录   | `operations/purge`      | `{ fs, remote }` |

**批量复制**：组合调用 `operations/copyfile`（单文件，跨盘同样适用）

```json
{ "srcFs": "drive:", "srcRemote": "photos/a.jpg", "dstFs": "s3:", "dstRemote": "backup/a.jpg" }
```

**批量下载**：复用 FR-02 打包流程，输入为多选清单（目录展开+文件直收）。

#### 4.5.5 边界与约束

- 并发上限：删除/复制并发 3，避免打爆 rcd。
- 部分失败：不中断整体，逐项记录结果，最终汇总 toast；失败项列表可展开查看。
- 批量复制默认**覆盖目标同名文件**（rclone copyfile 行为），确认 Dialog 中明示。
- 选择集在退出目录/切换远端时自动清空。

#### 4.5.6 验收标准

- [ ] AC-5.1 勾选 5 个文件（含 1 个目录）批量删除成功，汇总正确。
- [ ] AC-5.2 批量复制 3 个文件到另一远端成功，目标存在同名时覆盖确认生效。
- [ ] AC-5.3 批量下载 4 个文件打包为 zip，结构正确。
- [ ] AC-5.4 切换远端/目录后选择集自动清空。
- [ ] AC-5.5 模拟 1 项失败，整体不中断，汇总展示失败明细。

### FR-06 目录统计

#### 4.6.1 功能概述

查看目录（或单选文件）的总大小与文件数，用于容量规划与清理决策。

#### 4.6.2 交互流程

```
目录行 hover → "统计"按钮（BarChart3 图标）
    → 调用 operations/size（目录递归）
    → 结果 Dialog：总大小 / 文件数 / 无大小文件数 / 耗时
    → "复制结果"按钮一键复制统计文本
```

#### 4.6.3 API 契约

**接口**：`POST {rclone_rc}/operations/size`

| 参数   | 类型   | 必填 | 说明                          |
| :----- | :----- | :--- | :---------------------------- |
| fs     | string | ✅   | 远端                          |
| remote | string | ✅   | 目录路径；`""` 统计整个远端根 |

**响应**：

```json
{ "count": 128, "bytes": 5368709120, "sizeless": 3 }
```

| 字段     | 说明                                     |
| :------- | :--------------------------------------- |
| count    | 对象总数                                 |
| bytes    | 总字节数                                 |
| sizeless | 无大小属性的对象数（如部分云端链接文件） |

**错误处理**：超大目录统计耗时，展示 loading 态（Dialog 内 spinner），不阻塞其他操作。

#### 4.6.4 验收标准

- [ ] AC-6.1 统计目录返回正确文件数与总大小（与逐一求和一致）。
- [ ] AC-6.2 统计期间 UI 有 loading 态，完成后展示结果。
- [ ] AC-6.3 "复制结果"正确复制文本。

### 5.3 并发与性能策略

| 场景              | 策略                   |
| :---------------- | :--------------------- |
| 上传并发          | 3                      |

### 5.4 错误处理统一约定

- 所有操作成功 → `sonner.success`；失败 → `sonner.error`（含错误 message）。
- 逐项操作（批量/队列）失败不中断整体，最终汇总。
- 401 由 `NetworkClient` 全局拦截，页面无需处理。

### 5.6 安全

- 上传/下载均走 `NetworkClient`（自动附带鉴权头），不允许绕过。
- 大文件下载为前端内存 blob，>2GB 二次确认兜底，避免浏览器崩溃。

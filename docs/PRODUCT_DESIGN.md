> 更新日期：由项目迭代持续维护

---

## 1. 产品定位

**RcloneX** 是一个基于 Rclone Remote Control (RC) API 的现代化 Web UI 管理面板，核心价值：

- **可视化管理**：远程存储配置的 CRUD、连接测试、配额监控。
- **文件操作闭环**：跨远端浏览、上传、下载、复制、移动、分享。
- **任务自动化**：后台传输任务（sync/copy/move/bisync/check/cleanup）的创建与监控、定时规则。
- **本地化能力**：远程挂载（mount）、网络共享服务（serve: WebDAV/HTTP/FTP/DLNA）。
- **可观测性**：实时日志、传输速度、磁盘容量占比。

### 2.3 已知技术债（盘点时发现）

1. **Dashboard 页存在硬编码中文文案**，未走 i18n（如 "管理存储配置"、"实时传输流速" 等），需补齐翻译。
2. **services 层遗留大量 `console.log` 调试输出**（如 `config/services/index.ts`），生产环境应移除或降级。
3. **Config `createdAt`/`lastUsed` 为前端伪造**，非真实元数据（RC API 不提供），展示需谨慎语义。
4. **`getConfigOptions`（`config/get` 传 type）用法可疑**，RC 的 `config/get` 仅按 name 获取配置，选项模板实为前端内置，需核对是否冗余。

## 3. 缺口分析

对照成熟竞品（rclone-webui、RcloneNg、WebRclone 等）与用户核心场景，当前存在 **6 大结构性缺口**：

### 3.1 缺口总览

|  #  | 缺口                     | 严重度 | 说明                                                                        |
| :-: | :----------------------- | :----- | :-------------------------------------------------------------------------- |
| G1  | **文件操作链不闭环**     | 🔴 高  | 只能"看/删/复制"，不能上传、下载、重命名/移动、搜索，Explorer 名不副实      |
| G2  | **任务系统太薄**         | 🔴 高  | 无过滤规则、无并发/限速参数、无文件级进度详情、无历史记录，任务"黑盒"       |
| G3  | **定时任务引擎是伪需求** | 🔴 高  | `localStorage` + 前端定时器，**页面不打开就不执行**，无法兑现"定时备份"承诺 |
| G4  | **配置管理缺进阶能力**   | 🟠 中  | 无导入/导出、克隆、OAuth 支持（Google Drive/OneDrive 交互式授权缺失）       |
| G5  | **无数据可视化**         | 🟡 低  | 只有瞬时数字，无速度趋势曲线、无历史吞吐统计                                |
| G6  | **通信机制落后**         | 🟡 低  | 全部 3~5s 轮询，无 WebSocket/SSE 实时推送，任务结束无法主动通知             |

## 4. 分优先级功能设计

> 优先级定义：🔴 P0 核心可用性 → 🟠 P1 关键体验 → 🟡 P2 管理增强 → 🟢 P3 锦上添花

### 4.1 🔴 P0 — Explorer 文件操作闭环

#### 需求文档：文件操作增强

| 功能              | 用户场景                           | 功能规格                                                                            | RC API 支撑                                          |
| :---------------- | :--------------------------------- | :---------------------------------------------------------------------------------- | :--------------------------------------------------- |
| **上传文件**      | 拖拽本地文件到浏览器即可存入云盘   | 拖拽/点击多选上传；支持队列、进度条、失败重试；目录递归上传                         | `operations/uploadfile`（multipart 流式）            |
| **下载文件/目录** | 点击下载单文件；目录一键打包下载   | 单文件直接流式下载；目录先拉清单再打包（临时 serve zip 或前端组装）；大文件显示进度 | `operations/downloadfile`、`operations/list`（递归） |
| **重命名/移动**   | 单文件右键重命名、拖拽或对话框移动 | 复用现有复制对话框，增加"移动"模式；同盘内移动即重命名                              | `operations/moveto`                                  |
| **文件搜索**      | 递归搜索当前盘下文件               | 顶部搜索框 + 防抖；支持正则/通配符过滤；结果高亮 + 点击定位                         | `operations/list` + `opt.Filter` + `recurse`         |
| **多选批量操作**  | 勾选多个文件批量删除/复制/下载     | 全选/反选、shift 连选、底部批量操作栏、二次确认                                     | 组合 `operations/*`                                  |
| **目录统计**      | 查看文件夹占用大小/文件数          | 行内"统计"按钮，展示 Size / Count / 校验时间                                        | `operations/size`                                    |

**交互设计要点**：

- 文件行 hover 显示操作按钮组（预览/分享/复制/移动/重命名/删除）。
- 上传走独立拖拽区 + 任务队列抽屉（进度、取消、失败重试）。
- 所有破坏性操作（删除/移动覆盖）统一二次确认 + sonner 反馈。

#### 需求文档：任务系统增强

| 功能             | 规格                                                                                                               |
| :--------------- | :----------------------------------------------------------------------------------------------------------------- |
| **过滤规则**     | 新建任务时配置 Include/Exclude/FilterRule（前缀、正则、年龄、大小过滤），实时预览规则 JSON                         |
| **传输参数**     | Transfers、Checkers、Bwlimit、Retries、MinSize/MaxSize、MaxAge/MinAge、IgnoreExisting 等高级开关，统一进 `_config` |
| **任务详情抽屉** | 点击任务展开：文件级传输列表、速度/ETA、错误明细、日志片段、输出 JSON 查看                                         |
| **任务历史**     | 本地持久化最近 N 条任务记录（成功/失败/耗时/字节数），失败可一键重试                                               |
| **完成通知**     | 任务结束触发浏览器 Notification + 页面内通知中心红点                                                               |

### 4.2 🟠 P1 — 定时任务引擎重构

**现状问题**：纯前端 localStorage 调度，关闭页面即失效，无法兑现定时备份承诺。

**方案设计（三选一，建议 A+B 组合）**：

| 方案                              | 说明                                                                                      | 取舍                                 |
| :-------------------------------- | :---------------------------------------------------------------------------------------- | :----------------------------------- |
| **A. 常驻调度器**                 | 页面打开即启动调度循环（对齐 cron 粒度），记录执行历史 + 失败补偿；首次加载补跑错过的任务 | 实现快，仍依赖浏览器常开             |
| **B. 状态同步后端化（推荐中期）** | 新增轻量 Node 调度服务，RC 只暴露任务定义，UI 变为纯配置界面                              | 架构改动大，需新增服务端             |
| **C. 文档兜底**                   | 提供"导出为系统 cron 命令"（`rclone sync ...` 一键复制）                                  | 零成本，解决"浏览器必须常开"根本限制 |

**附加**：执行历史时间线、成功率统计、与 Tasks 页任务联动（跳转 job 详情）。

### 4.3 🟠 P1 — Dashboard 数据可视化

- **实时速度曲线**：前端 1s 采样 `core/stats` 写入环形缓冲，SVG/Canvas 绘制近 60s 吞吐曲线，叠加活跃任务数。
- **任务吞吐统计**：当日传输总量 / 平均速度 / 成功率卡片。
- **配额趋势**（可选）：本地记录每日配额快照，绘制 7 日趋势迷你图。

### 4.4 🟡 P2 — 配置管理进阶

- **导入/导出**：一键导出全部配置为脱敏 JSON（`config/dump`）；导入时逐项校验 + 批量创建（`config/create` 循环）。
- **配置克隆**：一键复制现有配置生成新配置（改 name）。
- **OAuth 支持**：对 Drive/OneDrive 等类型弹窗引导授权，经 `config/authresult` 完成回写（需 rcd 开启 oauth 回调）。
- **健康巡检**：可配置的定时连接探测（`operations/list` 根目录），失败推送通知 + Dashboard 状态红点。
- **凭据脱敏**：`config/get` 返回的密码/Token 一律掩码展示，仅编辑时明文输入。

### 4.5 🟡 P2 — 系统设置页（新增路由 `/settings`）

| 设置项               | 说明                                                                                       |
| :------------------- | :----------------------------------------------------------------------------------------- |
| **连接配置**         | RC 地址/Token 管理、**多 profile 快速切换**（测试/生产）、无鉴权模式（`--rc-no-auth`）支持 |
| **全局默认传输参数** | 新任务的默认 Transfers / Bwlimit / Checkers，作为表单默认值                                |
| **界面偏好**         | 语言/主题（已有）、列表默认视图、刷新频率                                                  |
| **数据管理**         | 清除本地缓存 / 历史 / 凭证                                                                 |

### 4.6 🟡 P2 — 实时通信与通知

- WebSocket/SSE 订阅 `core/stats`、`job/list`；**建议先做"降级轮询 + 心跳检测"，将通信层抽象为可替换接口**，避免阻塞其他迭代。
- 全局通知中心：任务完成/失败、配额超阈值、连接断开。

### 4.7 🟢 P3 — 锦上添花

- **文件预览**：图片/文本/PDF 内嵌预览（`operations/downloadfile` + objectURL），视频转 serve 流式播放。
- **加密盘向导**：`crypt` 类型配置引导（生成随机密码/盐值）。
- **审计日志**：本地记录所有写操作（增删改、配置变更），支持导出。
- **PWA**：可安装、离线壳（图标资产已具备 `appIcon.png`）。
- **Serve 管理增强**：serve 详情（地址/认证/访问量）、一键复制访问 URL。

## 5. 技术架构建议

### 5.1 目录规划（遵循 AGENTS.md 规范）

```
src/
├── hooks/
│   ├── use-transfer-stats.ts      # 速度曲线环形缓冲采样（配 *.test.ts）
│   └── use-task-scheduler.ts      # 定时调度器（配 *.test.ts）
├── pages/
│   ├── explorer/
│   │   ├── UploadQueue.tsx        # 上传队列抽屉
│   │   ├── SearchBar.tsx          # 递归搜索
│   │   ├── BatchBar.tsx           # 多选批量操作栏
│   │   └── FilePreviewDialog.tsx  # 文件预览
│   ├── tasks/
│   │   ├── TaskDetailDrawer.tsx   # 任务详情抽屉
│   │   └── FilterRuleEditor.tsx   # 过滤规则编辑器
│   └── settings/                  # 新增页面（index.tsx + services/index.ts）
└── shared/utils/
    └── transfer.ts                # 流式上传/下载统一封装（进度回调、错误处理）
```

### 5.2 关键设计决策

1. **上传下载统一封装** `shared/utils/transfer.ts`：axios + FormData 流式上传（带进度回调）；下载走 blob + 文件名，统一错误处理与超时控制。
2. **通信层抽象**：定义 `StatsProvider` 接口（WebSocket / SSE / 轮询三实现），默认轮询，后续无缝替换。
3. **任务参数收敛**：`CreateTaskParams` 扩展 `_config` 结构，前端表单 ↔ 参数 JSON 双向映射，保证 filter/transfers/bwlimit 等透传正确。
4. **i18n 全覆盖**：所有新增文案同步 `zh-CN` / `en-US`；同时补齐现有硬编码文案。
5. **测试配套**：services 新方法、hooks、utils 一律配 `*.test.ts(x)`。
